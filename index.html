Quickstart

Five minutes.
Then five experiments.

01

Add the playbooks.

Click "Add all 7 playbooks". One Devin session saves them all into your org. No copy-paste.

02

Add your secrets.

Add your Modal token under Settings → Secrets. Child sessions only see saved secrets, never ones pasted into chat.

03

Prepare the repo.

Run !hack_setup. It installs the sponsors' official agent skills, and every later session inherits them.

04

Run the lab.

Run !parallel_lab with your problem, metric and 5+ ideas. You get one PR per idea and a leaderboard.
