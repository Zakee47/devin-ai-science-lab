Quickstart

About 5 minutes from here to five experiments running in parallel.

Install the playbooks

Click the button above. Devin saves all 7 into your org with their macros. One session, no copy-paste.

Add your secrets

In Devin, go to Settings → Secrets and add your Modal token. Child sessions can only see secrets saved there, never ones pasted into chat.

Prepare the repo

Run !hack_setup on your team repo. It installs the sponsors' official agent skills so every later session inherits them.

Run the lab

Run !parallel_lab with your track problem, metric and 5+ ideas. You get a PR per idea and one leaderboard PR.

The playbooks

Each "Create in Devin" button opens Devin's new-playbook page with the full text filled in; press Save and it's yours. DeepMind and Anthropic tools are deliberately out of scope here.

What the challenge asks for

Run !parallel_lab and you produce all of this by default.

  • 5+ Devin sessions in parallel, each on a different idea: a model, a method, an optimisation, an analysis.
  • Every session ends in a branch or PR with a result, not an opinion: a metric from the team's shared eval script.
  • GPU work runs on Modal, with the app link and cost recorded in the PR.
  • One comparable baseline and split fixed before fan-out, so five results line up against each other.
  • A leaderboard PR with deltas, uncertainty and the negative results kept in. That's your 2-minute demo.
